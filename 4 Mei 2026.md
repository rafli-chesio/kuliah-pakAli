## 1. Tambah di Androidmanifest.xml
Tambah nya di paling atas 
:
```xml
    <queries>

        <intent>
            <action android:name="android.intent.action.VIEW" />
            <data android:scheme="https" />

        </intent>
```

## 2. Tambah di file kotlin:

```xml
        pindah.setOnClickListener {
            val intent = Intent(Intent.ACTION_VIEW, Uri.parse("https://www.unimed.ac.id/"))
            if (intent.resolveActivity(packageManager) != null) {
                startActivity(intent)
            } else {
                Toast.makeText(this, "Tidak ada browser yang tersedia", Toast.LENGTH_SHORT).show()
            }
        }
```

## 3. Tambah di activity_main.xml (xml paling atas pokoknya di res/layout/...)

```xml
    <Button
        android:id="@+id/web"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        app:layout_constraintTop_toTopOf="parent"
        app:layout_constraintBottom_toBottomOf="parent"
        android:text="Pindah Aplikasi"
        app:layout_constraintStart_toStartOf="parent"
        app:layout_constraintEnd_toEndOf="parent"/>
```
